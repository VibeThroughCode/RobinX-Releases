# RobinX Releases

Public release downloads for RobinX applications.

This repository is a central home for downloadable application binaries, such as ZIP archives, installers, and executables. Source code is maintained separately in private repositories; this repository contains no application source code.

## Downloads

| Application | Version | Platform | Download |
| --- | --- | --- | --- |
| [ZPL Studio](https://github.com/VibeThroughCode/RobinX-Releases/releases/tag/zpl-studio-v1.0.0) | v1.0.0 | Windows 11 x64 | [Download ZIP](https://github.com/VibeThroughCode/RobinX-Releases/releases/download/zpl-studio-v1.0.0/ZPL-Studio-v1.0.0-win-x64.zip) |

**ZPL Studio:** extract the entire ZIP and double-click `ZPL-Studio-win-x64/ZplStudio.exe`. Keep the included DLL files, `Rendering`, and `Licenses` folders beside the executable. This portable build includes .NET, so no separate .NET installation is required. Open **Guide** or press **F1** for the offline manual.

Visit the [Releases page](https://github.com/VibeThroughCode/RobinX-Releases/releases) for release notes, checksums, and downloads for all applications. Download application files from the release's **Assets** section.

## Release naming

Each release is labeled with its application name and version. Tags also include the application name so releases for different applications can share this repository.

For example:

| Release title | Tag |
| --- | --- |
| ZPL Studio v1.0.0 | `zpl-studio-v1.0.0` |
| SMTP Studio v1.2.0 | `smtp-studio-v1.2.0` |
| FileGrabber v1.0.0 | `filegrabber-v1.0.0` |

These are naming examples, not a list of available downloads. Release notes will describe changes, identify the relevant platform, and link back to the application's website where appropriate.
