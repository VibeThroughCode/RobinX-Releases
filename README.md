# RobinX Releases

Public release downloads for RobinX applications.

This repository is a central home for downloadable application binaries, such as ZIP archives, installers, and executables. Source code is maintained separately in private repositories; this repository contains no application source code.

## Downloads

Visit the [Releases page](https://github.com/VibeThroughCode/RobinX-Releases/releases), find the application and version you want, and download the appropriate file from that release's **Assets** section.

Releases will be added as application builds become available.

## Release naming

Each release is labeled with its application name and version. Tags also include the application name so releases for different applications can share this repository.

For example:

| Release title | Tag |
| --- | --- |
| ZPL Studio v1.0.0 | `zpl-studio-v1.0.0` |
| SMTP Studio v1.2.0 | `smtp-studio-v1.2.0` |
| FileGrabber v1.0.0 | `filegrabber-v1.0.0` |

These are naming examples, not a list of available downloads. Release notes will describe changes, identify the relevant platform, and link back to the application's website where appropriate.
